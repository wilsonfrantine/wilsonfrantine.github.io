## Conversão no navegador

**PhotonPDF** converte arquivos compatíveis para PDF inteiramente no navegador, sem processamento em servidor ou envio dos arquivos para upload.

### Como usar

Abra a demonstração, selecione um arquivo aceito pela aplicação e baixe o PDF gerado. O formato e as opções disponíveis estão descritos na interface.

### Características

* Processamento local no navegador.
* Interface web responsiva.
* Código disponível no repositório para execução local.
